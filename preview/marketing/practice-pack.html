1. Simplify: 4x + 3 + 2x − 5

Hint

Combine terms with the same variable. Combine plain numbers separately.

Worked answer

4x + 2x = 6x and 3 − 5 = −2. Answer: 6x − 2.

2. Solve: 3x + 6 = 18

Hint

Undo addition first, then multiplication. Do the same operation on both sides.

Worked answer

Subtract 6: 3x = 12. Divide by 3: x = 4. Check: 3(4) + 6 = 18.

3. Solve: 2(x + 3) = 14

Hint

You can divide both sides by 2 before subtracting 3.

Worked answer

x + 3 = 7, so x = 4. Check: 2(4 + 3) = 14.

4. Solve: −2x > 8

Hint

When you divide an inequality by a negative number, reverse its direction.

Worked answer

Divide by −2 and reverse >: x < −4. For example, x = −5 gives 10 > 8.

5. Find y when x = 4: y = 2x + 1

Hint

Replace x with 4, multiply, then add.

Worked answer

y = 2(4) + 1 = 9. The point (4, 9) lies on this line.

6. A notebook costs $3. You also buy a $2 pen. Your total is $17. How many notebooks did you buy?

Hint

Let n be the number of notebooks. Write 3n + 2 = 17.

Worked answer

Subtract 2: 3n = 15. Divide by 3: 5 notebooks. Check: 5 × $3 + $2 = $17.
